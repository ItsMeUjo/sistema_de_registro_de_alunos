Esse sistema foi feito para prática de código python

#adicionando aluno
digite os dados do aluno nos respectivos campos e adicione uma imagem
clique em adicionar após preencher toda a tabela
o aluno aparecerá no banco de dados

#atualizando aluno
digite o ID do aluno no campo de busca e clique em procurar
os dados do aluno e a foto aparecerão nos campos da tabela
altere os dados que quiser e clique em atualizar
os dados do aluno serão atualizados no banco de dados

#deletando aluno
ditie o ID do aluno no campo de busca e clique em procurar
os dados do aluno e a foto aparecerão nos campos da tabela
clique em deletar
o aluno será excluído do banco de dados
